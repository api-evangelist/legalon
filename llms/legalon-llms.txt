# LegalOn

> LegalOn Technologies builds AI software for in-house legal teams, corporate legal
> operations, and law firms: AI contract review and redlining, contract playbooks,
> matter management, a contract data vault, translation, entity and board management,
> and agentic legal workflows, with a Microsoft Word integration. LegalOn publishes a
> REST contract API (OAuth 2.0 client_credentials) for contract files and contract
> metadata, but does not publish an open API reference — access is arranged with the
> vendor.

Generated by the API Evangelist enrichment pipeline on 2026-07-19 from apis.yml and the
artifacts in this repository. Not published by LegalOn.

## API

- [LegalOn Contract API announcement (phase 2, 2026-07-13)](https://legalontech.jp/10843/): Contract file upload/retrieve/update/delete, contract metadata register/update/retrieve, related-document linking, contract listing. OAuth 2.0 client_credentials, workspace- and role-scoped.
- [LegalOn API connectivity announcement (phase 1)](https://legalontech.jp/10478/): First phase of LegalOn API integration.
- API host: https://api.legalontech.com (host resolves; all unauthenticated requests return 403)
- No public OpenAPI, AsyncAPI, GraphQL schema, SDK, CLI, MCP server, or developer portal was found.
